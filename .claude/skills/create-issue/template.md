# 이슈 본문 템플릿

타입에 맞는 템플릿 하나를 골라 채운다. 해당 없는 섹션은 지운다.

## feat · refactor · chore · docs · test · ci

```markdown
## 배경
<왜 필요한지 — 누가, 어떤 상황에서>

## 할 일
- [ ] <구체적인 작업 1>
- [ ] <구체적인 작업 2>

## 완료 조건
- <무엇이 되면 끝인지 — 확인 가능한 문장으로>

## 참고
- <관련 파일 경로, 문서, 이슈 링크>
```

## fix

```markdown
## 현상
<무엇이 잘못되는지>

## 재현 방법
1. <단계>
2. <단계>

## 기대 동작
<원래 어떻게 되어야 하는지>

## 원인 추정
<코드를 확인했다면 파일 경로와 함께. 모르면 이 섹션 삭제>

## 참고
- <에러 메시지, 로그, 관련 파일>
```
